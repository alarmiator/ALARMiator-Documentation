# Broadcast-Nachricht

Unter **Admin → Broadcast-Nachricht** kannst du als Admin eine Benachrichtigung an deine Mitglieder schicken. Eine Broadcast Nachricht wird als Notification am Handy über die ALARMiator Mobile App auftauchen. Ähnlich wie eine Whatsapp Nachricht oder eine SMS.

![Broadcast-Nachricht](/img/ui/admin/broadcast.png)

Wähle die **Gruppen** aus, die die Nachricht erhalten sollen, und gib die **Nachricht** ein (höchstens 160 Zeichen). Ohne Auswahl geht die Nachricht an alle Mitglieder mit der Mobile-App. Sie wird sofort gesendet.
