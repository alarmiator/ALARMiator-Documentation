# Rollen anlegen

Navigiere zu **Stammdaten → Rollen** und klicke auf **+ Neu**.

![Rolle anlegen](/img/ui/stammdaten/rolle-anlegen.png)

Gib den **Rollennamen** ein, hier zum Beispiel "Maschinist". Die Rolle kann nun an alle Maschinisten unter **Stammdaten → Mitglieder** gegeben werden. Du kannst die Mitglieder auch gleich beim Anlegen der Rolle zuweisen.
