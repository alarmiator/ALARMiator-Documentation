# Alarmwegematrix einstellen

Navigiere zu **Alarmierung → Alarmierungswege**. Du solltest folgendes sehen:


![Alarmierungswege](/img/ui/alarmierung/alarmwege.png)



Hier kannst du für jedes Mitglied einstellen, über welchen Weg es Alarmierungen empfangen kann. Ist der Haken gesetzt empfängt ein Mitglied über diesen Weg Alarmierungen.



Du kannst einen Alarmierungsweg für ein Mitglied mit einem Klick auf das blaue Megafon-Icon neben der Checkbox überprüfen.


<InfoBox type="warning" title="Alarmierung prüfen">
Es gibt keine extra Bestätigung. Klickst du das blaue Icon wird ein Probealarm an dein Mitglied geschickt!
</InfoBox>


Ist die Alarmwegematrix konfiguriert das zugehörige Plugin unter **Admin → Plugins** jedoch nicht, wird der Alarmierungsweg erst mit aktivieren des Plugins benutzt.
