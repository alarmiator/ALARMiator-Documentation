# Gruppen anlegen

Navigiere zu **Stammdaten → Gruppen** und klicke auf **+ Neu**.

![Gruppe anlegen](/img/ui/stammdaten/gruppe-anlegen.png)

Vergib einen **Gruppennamen** und ein **Kürzel** und wähle die **Organisation**. Mit **Gruppe kann alarmiert werden** legst du fest, ob die Gruppe in der Alarmierung verwendet werden kann. Unten kannst du der Gruppe direkt Mitglieder zuweisen.

Über die Gruppen wird gesteuert, welches Mitglied welche Alarmierungen erhält. Dazu können Gruppen Mitgliedern auch später zugewiesen werden unter **Stammdaten → Mitglieder**.

Gruppen gehören zu einer Organisation, sie können aber an alle Mitglieder organisationsunabhängig zugewiesen werden.

Solltest du die gleichen Gruppen an Mitglieder verschiedener Organisationen vergeben wollen, empfiehlt es sich eine übergeordnete Organisation anzulegen, der die Gruppen gehören.

Wie man Organisationen anlegt findest du im [zugehörigen Guide](/docs/eine-organisation-anlegen).
