# Übersicht - Dashboard

Die Startseite (**Home**) bietet jedem Benutzer einen direkten Überblick. Im Bereich **Übersicht** siehst du Kennzahlen der Module, die du lesen darfst, z.B. aktive Alarmierungsprofile, inaktive Endgeräte, aktive Einsätze, auslaufende G26.3 und fällige Wartungen. Rot markierte Kacheln zeigen Handlungsbedarf.

![Startseite mit Kennzahlen](/img/ui/admin/startseite.png)

In der Zeile **System** siehst du die Anzahl der aktiven eingehenden und ausgehenden Plugins und die Laufzeit des Servers. Eingehende Plugins sind z.B. das KatSys-Plugin oder die REST API, ausgehende z.B. die Weitergabe von Alarmierungen an die ALARMiator Mobile Apps, MQTT oder Divera. Verwaltet werden sie unter **Admin → Plugins**.

Darunter findest du **Meine Alarmierung** und **Meine Termine als iCal-Feed**, siehe [Persönliche Startseite](/docs/persnlichestartseite).
